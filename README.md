# سنابل — تطبيق توزيع الطحين

## البنية
`index.html` التطبيق كاملاً في ملف واحد (يفتح مباشرة من الهاتف أو الكمبيوتر) · `public/` الأيقونات و manifest و sw.js · `scripts/` البناء والفحص · `tests/` الاختبارات · `.github/workflows/ci-cd.yml` نظام الجودة والنشر.

## نظام الجودة (QA) — يعمل تلقائياً عند كل رفع
1. **فحص ثابت:** صحة الكود، وجود كل عناصر الواجهة التي يطلبها الكود، وجود الأيقونات والملفات، ومنع وجود أي رمز Telegram داخل الكود.
2. **اختبارات وحدة (7):** حساب الحصة والأكياس، حالات الاستلام، المبالغ، البحث العربي، ترتيب الصفحات، حماية HTML.
3. **اختبار متصفح (Playwright):** يفتح التطبيق، يتنقل بين الصفحات، يضيف عائلة ويسلّمها. (غير إلزامي في البداية؛ بعد أول نجاح احذف سطر `continue-on-error` من الملف.)
4. **النشر لا يتم إلا إذا نجح الفحص والاختبارات.** وإن فشل شيء تصلك رسالة من GitHub ويبقى الإصدار السابق شغالاً.
تشغيل محلي: `npm run verify`.

## مراقبة الأخطاء (Sentry)
1. أنشئ حساباً في sentry.io ← New Project ← **Browser JavaScript**.
2. انسخ رابط **DSN** وألصقه في التطبيق: الإعدادات ← مراقبة الأخطاء ← حفظ، ثم «خطأ تجريبي» للتأكد.
3. في Sentry ← Alerts: فعّل تنبيه «New issue» على بريدك لاكتشاف الأخطاء مبكراً.
الخصوصية: لا تُرسل أسماء ولا بيانات عوائل ولا نقرات ولا مدخلات، فقط تفاصيل الخطأ التقنية ورقم الإصدار.

## إشعارات الأخطاء داخل التطبيق
أي خطأ يحدث يظهر فوراً كتنبيه، وتجد على الشاشة العلوية **جرساً** بعدّاد أحمر. اضغط عليه لترى الأخطاء (الوقت، الرسالة، المكان، الإصدار) واضغط «نسخ التقرير» وأرسله لمن يصلح الخلل. وإذا أدخلت المنظمة والمشروع ورمز قراءة Sentry في الإعدادات يجلب التطبيق مشاكل Sentry كل 5 دقائق ويُنبّهك بالجديد منها.
